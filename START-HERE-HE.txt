   והנתונים שבה נשמרים רק בדפדפן שבו פותחים אותה (אם הדפדפן מאפשר).
   היא לא מסתנכרנת בין מחשב לטלפון ולא משתפת נתונים.

2) כדי להפעיל את האתר האמיתי עם שמירה בענן ומשתמשות:
   • היכנסי ל־supabase.com/dashboard וצרי פרויקט.
   • העתיקי והריצי את כל supabase/schema.sql ב־SQL Editor.
   • השאירי אימות אימייל פעיל (Confirm email).
   • העתיקי .env.example לקובץ .env והגדירי Project URL ומפתח publishable.
   • פתחי את תיקיית הפרויקט ב־Cursor, הריצי npm install ואז npm run dev.

אם כבר הרצת schema.sql לפני עדכון הצעדים, אין צורך להריץ אותו שוב.
   במקום זאת הריצי את supabase/2026-11-01_add_steps.sql ב־SQL Editor.

3) כדי להעלות אותו לאינטרנט:
   • העלי את הקבצים (ללא .env) לריפוזיטורי פרטי ב־GitHub.
   • Import Project ב־vercel.com/new.
   • הגדירי שני Environment Variables כמו ב־.env.
   • עדכני Site URL ו־Redirect URLs תחת Authentication ב־Supabase.

4) כדי לשתף עם משתמשות אחרות:

   • כל משתמשת נרשמת עם אימייל וסיסמה.
   • בעמוד "שיתוף התקדמות" צרי הזמנה למייל שלה, הגדירי משקל/היקפים.
   • היא נכנסת באותו המייל ומאשרת. אפשר לבטל הרשאה בכל רגע.
